# Results

Raw evidence linked from the [log](../log/): CSVs, scope screenshots, photos, audio clips. Name
each file after its log entry, `YYYY-MM-DD-short-name-<what>.<ext>`, such as
`2026-11-14-dial-tone-scope.png`.

Keep files small: PNG or JPG photos under a few MB, short audio clips. Larger captures belong
outside git.
